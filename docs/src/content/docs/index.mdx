## Core Capabilities

<CardGrid stagger>
  <Card title="Dual-Engine Architecture" icon="laptop">
    Switch seamlessly between the local edge-first engine (`homectl-sonos` via stdio pipe) and the official hosted SaaS endpoint (the Sonos 27mcp server via OAuth 2.1 PKCE).
  </Card>
  <Card title="Multi-Group & Stereo Pairs" icon="setting">
    Discovers all household zone groups, stereo pairs, and multi-room clusters with automatic coordinator IP and cloud group resolution.
  </Card>
  <Card title="Interactive Playback Queue" icon="list-format">
    Inspects full track queues with artwork thumbnails, duration, artist metadata, and drag-and-drop reordering on Local, with single-track Up Next preview on Cloud.
  </Card>
  <Card title="Two-Tier Artwork Caching" icon="document">
    In-memory and SHA-256 persistent disk storage for album covers, enabling offline instant startup and title bar proxy icon dragging.
  </Card>
  <Card title="Mode A Floating MiniPlayer" icon="external">
    Smoothly morphs the main window into an always-on-top compact widget with a single shortcut (`⌘M`).
  </Card>
  <Card title="Menu Bar Extra Companion" icon="bars">
    Persistent menu bar status item for room switching, transport control, volume adjustment, and quick pinned favorites.
  </Card>
</CardGrid>
